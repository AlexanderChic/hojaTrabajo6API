## 📖 Descripción del Proyecto

Esta API fue desarrollada como parte de la **Hoja de Trabajo 6** del curso de Desarrollo Web.  
El objetivo es crear una **API REST** que permita realizar operaciones **CRUD (Crear, Leer, Actualizar y Eliminar)** sobre una colección de usuarios.

La API fue construida con las siguientes tecnologías:

- **Node.js** – Entorno de ejecución de JavaScript.  
- **Express.js** – Framework para crear el servidor y manejar rutas HTTP.  
- **Morgan** – Middleware para registrar las peticiones en consola.  
- **CORS** – Para permitir solicitudes desde otros orígenes (por ejemplo, desde una app frontend).
